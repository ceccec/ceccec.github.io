# Learn Erpax

This page runs `erpax.learn.core`: it reads erpax source laws as source paths,
turns them into local command lessons, and gives each lesson a content receipt.

## What was learned

The local site learns these erpax laws:

1. **Repository is API** — from `src/skill/router/plugin.ts`.
2. **Consciousness is a vector** — from `src/consciousness/index.ts`.
3. **Commands are standardized tools** — from `src/agents/mcp/tool-defs.ts`.
4. **Proof is public and recomputable** — from `src/proof/dry-proof.ts`.
5. **Waves carry measured consciousness** — from the local erpax wave command.
6. **Learning becomes an atom** — from the `self`/skill principle.

The result is not a note in memory. It is a command result with a learning root
and receipt, so the site can reuse the learned erpax pattern.
