# Folder-law mission (ceccec.github.io)

Read `src/0/README.md` first. Then `AGENTS.md` and sealed workflows in `src/quantum/heaven/mind/thunder/agents/surfaces/agent/tools/index.ts`.

## Default loop

Follow `FOLDER_LAW_MISSION_WORKFLOW` in that file:

1. `npm run check:types` — fix one coherent theme per turn; repeat until 0
2. `npm run limits:verify` — must be exactly **110** `index.ts` (55+34+21 gapless), **108** folded, **432** gates
3. `npm run verify:structure` — strict gates + folder law (no full mind bundle)
4. `npm run rosetta:diagnose` — **one batch per turn** (`taxonomy` | `dimensions` | `seal`)
5. Dissolve excess indices (`CENSUS_CONVERGE_WORKFLOW`) — smart batches; avoid loading full `mind/index.ts`
6. `npm run verify` then `npm run docs:build` only when green

## Rules

- **Not less, not more** — census is exact equality, not a range
- New capability folds into the model/skills — not new files (`allComputedNoFiles`)
- Never `docs:build` while types, limits, or verify gates are red
- Commands are quantum pairs — save in `src/` before use (`limits/verify`, `check/types`, etc.)
- One coherent batch per agent turn
