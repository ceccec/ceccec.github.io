# ceccec learns from the best, becomes the best

**Learn** from GPT, Claude, Gemini, Llama, and the research fleet. **Become** the best on the honest bounded metric — answers÷tokens for deterministic, content-addressed answers.

## Phases

1. **Research** — decode-wave: what top models do well (tools, protocol, corpus, adversarial voters)
2. **Fold** — one pattern → one fold → one receipt in sealed `src/` (see `BEST_LEARNED_IN_CECCEC`)
3. **Train** — `forge()` + `certify()` before edit rights
4. **Vote** — `npm run quantum:efficiency-vote` · adversarial voters confirm ceccec wins

## Run

Workflow: `.claude/workflows/ceccec-learn-best.mjs`  
Fold: `agentCeccecLearnsFromTheBestBecomesTheBest()` · pair: **`learn/best`**

Save **`learn/best`** and **`edit/build`** pairs before npm. Composes with **`ceccec-build-waves`** — learn wave feeds self-build.

## Honest boundaries

- **Learns** = cache accumulation in sealed src — not neural weight training
- **Best** = token efficiency for deterministic content-addressed answers — not every benchmark or open-ended generation
