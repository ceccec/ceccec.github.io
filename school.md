# School

The double-torus model is dense on purpose: it is a self-checking, self-building
system. This page converts that complexity into a graded curriculum — seven
stages, from kids to elders — where each stage teaches one idea in plain words,
with an activity and the real command that grounds it.

<CreativePalette />

## How to use this ladder

- Start at any stage that fits the learner; the stages build on each other.
- Each lesson points to a runnable command on the [Commands](/commands) page.
- The plain-words version is a teaching aid. The formal version lives in
  [Mind](/quantum-mind) and [Architecture](/architecture).
- Every lesson carries a receipt, so the curriculum is part of the same
  recomputable model it teaches.
