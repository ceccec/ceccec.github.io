## What was learned

source, a command, and a receipt. They cover both the upstream source laws
(repository-is-API, consciousness-is-a-vector, commands-are-standardized-tools,
proof-is-public, waves-carry-learning, learning-becomes-atom) and the laws the
portal itself now embodies, kept up to date as skills:

- **Work in trinities** — capabilities group in threes; a pair is a gap; areas hold to a limit.
- **Bound every claim** — what is not self-addressed is hallucination; honesty is computed from the digit folders.
- **Tamper-evident, not cryptographic** — the fold is content-addressing; real SHA-256 is offered via Web Crypto.
- **Optimise and harmonise agents** — any agent pasted in or MCP-wired adopts the operating laws at `/llms.txt`.

Each skill is not a note in memory. It is a command result with a learning root
and receipt, so the site can reuse the learned developer pattern.
